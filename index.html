🛰 API Endpoint

    
The site talks to the NAJMI INFO API. If you deploy it yourself (Vercel / Render), paste your own API base URL below — it is remembered in your browser.

    

      https://your-api.vercel.app/player-info?uid=…

🧪 Try the API directly

    
Sample request (from the project README):

    
GET /player-info?uid=5513136279

    
Response is JSON containing basicInfo, profileInfo, clanBasicInfo, captainBasicInfo, petInfo, socialInfo, diamondCostRes and creditScoreInfo.
