# 🔥 SHIVRAJ INFO APIS — Free Fire Player Lookup

Final static front-end for Free Fire player lookup with a polished responsive UI.
Built with pure HTML, CSS and JavaScript for easy deployment on Vercel, GitHub Pages or any static hosting.

## Included files

- `index.html` — page structure
- `style.css` — final responsive UI styling
- `script.js` — lookup logic, result rendering, API base URL settings
- `.nojekyll` — optional GitHub Pages compatibility

## API behavior

The site requests:

```text
GET /player-info?uid=<UID>&region=<REGION>
```

Default behavior:

- Uses the current deployment origin as API base URL.
- You can save a custom API base URL from the UI settings section.
- Region is optional.
- JSON export is included.
